# Expo React Native Android Template

Production-ready Expo React Native Android application boilerplate.

## Configuration Details
- **Android Package**: `com.multimodel.devos` (configured in `app.json`).
- **EAS Build**: Setup profiles for `development`, `preview` (staging APK), and `production` (Play Store AAB).
- **Security**: Device encryption credentials handled via `expo-secure-store`.
- **API Client**: Service endpoints routed through environment variables configuration dynamically in `app.config.ts`.
