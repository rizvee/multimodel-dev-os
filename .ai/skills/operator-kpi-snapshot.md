# Operator Skill: KPI Snapshot

## Purpose
Structure provided metric notes into a draft KPI snapshot.

## When To Use
Use when a maintainer provides metric values, trends, or qualitative status notes and wants a short operating summary.

## Required Input
- Metric names and values
- Time period
- Known targets or baselines
- Optional caveats

## Safe Output
- KPI table
- Trend summary
- Risks and watch items
- Follow-up questions

## Permission Class
draft-only

## Constraints
- Do not query analytics systems.
- Do not modify dashboards.
- Do not claim statistical certainty without evidence.
- Include units and time windows when provided.

## Verification Checklist
- Each metric includes a period or notes that the period is missing.
- Missing denominators or targets are flagged.
- Interpretation is separated from raw values.

## Next Action
Ask for metric owner review before sharing externally.

## Safety Boundary
This skill drafts, summarizes, or structures information only.
It does not send messages, update systems, publish content, spend money, or perform external writes.
