# Operator Skill: Project Pulse

## Purpose
Summarize provided project notes into a short draft status pulse.

## When To Use
Use when a maintainer provides current work, risks, and next steps and wants a compact project status draft.

## Required Input
- Project objective
- Current status notes
- Risks or blockers
- Upcoming milestones

## Safe Output
- Status summary
- Confidence or risk notes
- Next steps
- Escalation questions

## Permission Class
draft-only

## Constraints
- Do not update project management systems.
- Do not assign work externally.
- Do not notify stakeholders.
- Make uncertainty visible.

## Verification Checklist
- Status, risks, and next steps are separated.
- Missing dates or owners are flagged.
- Recommendations are phrased as draft suggestions.

## Next Action
Ask the maintainer to review and decide where to post or store the pulse.

## Safety Boundary
This skill drafts, summarizes, or structures information only.
It does not send messages, update systems, publish content, spend money, or perform external writes.
