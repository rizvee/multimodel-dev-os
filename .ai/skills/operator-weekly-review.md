# Operator Skill: Weekly Review

## Purpose
Convert provided weekly notes into a draft review with outcomes, blockers, risks, and next actions.

## When To Use
Use when a team or maintainer wants a structured weekly operating summary from supplied notes.

## Required Input
- Completed work
- Planned work
- Blockers
- Metrics or observations

## Safe Output
- Draft weekly review
- Highlights
- Risks and blockers
- Next action list

## Permission Class
draft-only

## Constraints
- Do not post updates to chat, project tools, or email.
- Keep examples generic.
- Flag missing context instead of filling gaps.

## Verification Checklist
- Wins, blockers, and next actions are distinct.
- Dates and owners are included only when provided.
- Open questions are explicit.

## Next Action
Ask the maintainer to approve, edit, or route the draft manually.

## Safety Boundary
This skill drafts, summarizes, or structures information only.
It does not send messages, update systems, publish content, spend money, or perform external writes.
