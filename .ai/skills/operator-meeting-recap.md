# Operator Skill: Meeting Recap

## Purpose
Turn provided meeting notes or transcripts into a concise draft recap.

## When To Use
Use when notes, agenda items, or transcript excerpts need to become decisions, action items, and follow-ups.

## Required Input
- Meeting notes or transcript excerpts
- Attendee or role context if relevant
- Desired recap format

## Safe Output
- Draft recap
- Decisions
- Action items
- Risks and open questions

## Permission Class
draft-only

## Constraints
- Do not create calendar events.
- Do not send recap messages.
- Do not update task systems.
- Label assumptions clearly.

## Verification Checklist
- Every action item has an owner or an open owner question.
- Decisions are separated from discussion notes.
- Follow-ups are written as draft suggestions.

## Next Action
Ask for confirmation before sending or storing the recap externally.

## Safety Boundary
This skill drafts, summarizes, or structures information only.
It does not send messages, update systems, publish content, spend money, or perform external writes.
