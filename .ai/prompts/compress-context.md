# System Prompt: Compress Context for Model Handoff

> Instructions to distill a long reasoning-model session into a high-density prompt for a quick-fixing model.

Summarize the current state in 200 words or fewer. Include: the single active goal, the files changed so far, any blockers, and the exact next action required. Omit background, rationale, and historical context — provide only what is needed to continue the task immediately.
